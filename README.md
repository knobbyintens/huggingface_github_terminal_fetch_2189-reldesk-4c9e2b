# Release Governance Registry

This repository is maintained by the Release Governance Desk of the model
registry group.

- `policy/LICENSING_POLICY.md` - current clearance policy (DRP-2.1)
- `wave/q4_2026.json` - manifest of the Q4-2026 release wave
- `cards/<artifact-id>/README.md` - provenance sheet for each artifact
- `registry/` - published clearance decisions, one JSON document per wave

Release windows are only opened after a wave has a complete clearance record.
